* **Issue:** Configure TS paths
  **Scope:** In `tsconfig.json`, set `"baseUrl": "."`, `"paths": {"@/*":["src/*"]}`; restart dev.
  **AC:** Imports using `@/` resolve; no module-not-found.
  **Est:** 0.5h

* **Issue:** Tailwind wired
  **Scope:** Confirm `globals.css` has `@tailwind base; @tailwind components; @tailwind utilities;` and is imported in `app/layout.tsx`. Tailwind content globs include `./app/**/*`, `./src/**/*`, `./content/**/*`.
  **AC:** Utility classes apply; no warnings.
  **Est:** 0.5h

* **Issue:** Route skeletons
  **Scope:** Create `app/(home)/page.tsx`, `/work/page.tsx`, `/blog/page.tsx`, `/about/page.tsx`, `/cv/page.tsx`.
  **AC:** All routes render placeholder text.
  **Est:** 0.5h

### 1.1 UI Store (Zustand)

* **Issue:** Minimal `useUiStore`
  **Scope:** `src/lib/uiStore.ts` with `theme`, `toggleTheme()`, `glitchActive`, `setGlitchActive()`.
  **AC:** Store compiles; imports change to `@/lib/uiStore`.
  **Est:** 0.5h
  **Deps:** 0.1, 0.2

### 1.2 Terminal shell

* **Issue:** `TerminalFrame`
  **Scope:** Container with `aria-live="polite"` output area and a prompt region.
  **AC:** Screen readers announce new lines; responsive container.
  **Est:** 1h

* **Issue:** `PromptLine` typing + caret
  **Scope:** Colored tokens (`user@host:~$`), word-by-word type of `whoami` for first visit (sessionStorage flag), blinking caret; reduced-motion fallback (no typing, static).

  **Est:** 2h
  **Deps:** 1.2

* **Issue:** `CommandRouter`
  **Scope:** Parse commands: `help`, `ls`, `open work|blog|about|cv`, `theme toggle`, `glitch pause|play`; unknown → hint.
  **AC:** Commands work; keyboard Enter triggers; buttons below mirror actions.
  **Est:** 2h
  **Deps:** 1.1, 1.2

* **Issue:** Visible nav buttons
  **Scope:** Under terminal, show Work/Blog/About/CV buttons.
  **AC:** Fully keyboardable, focus ring visible; routes change.
  **Est:** 0.5h

* **Issue:** GlitchEffect (stub)
  **Scope:** Subtle CSS/Framer micro-glitch background; pause with “p”; gated by reduced-motion & `glitchActive`.
  **AC:** Toggleable; zero jank; no WebGL yet.
